# PostHog event fields

Kit sends the event fields below for each captured event. `Report` admits each event's configured product properties and adds the shared properties. After SDK serialization, the transport keeps only the shared properties and that event's configured product properties, including on redirect replays. It always removes `$os`, `$os_version`, `$os_distro`, and `$go_version`, even if allowed by product configuration. Construction accepts these declarations and logs one warning per name. Events that supply them still upload their other allowed properties. Use another name to send a product value. `goos` and `goarch` remain. Valid JSON objects without a `batch` field and POST requests with no body pass through unchanged. Malformed batch payloads return an error before sending.

The batch envelope keeps only `api_key` and `batch`. Each event keeps only `event`, `distinct_id`, `uuid`, `timestamp`, and `properties`. An event without `properties` retains that shape. Daily deduplication uses the filtered product key before SDK serialization, so it can still distinguish values under a stripped name locally.

| Field | Source | When present |
| --- | --- | --- |
| `event` | Event name passed to `Capture` or `Report`, admitted by `WithAllowedEvent` | Every event |
| `distinct_id` | Anonymous installation or instance ID supplied as `Options.DistinctID` | Every event |
| `uuid` | Random event UUID generated by posthog-go | Every event |
| `timestamp` | Kit's capture time in UTC | Every event |
| `properties.application` | `Options.Application` | Every event |
| `properties.source` | `Options.Source`, defaulting to `daemon` | Every event |
| `properties.version` | `Options.Version` | Every event, empty if unspecified |
| `properties.commit` | `Options.Commit` | Every event, empty if unspecified |
| `properties.distribution` | Build channel set at link time with `-X go.kenn.io/kit/telemetry/posthog.distribution=<channel>`, such as `homebrew` | Every event, empty for source builds |
| `properties.goos` | Go's `runtime.GOOS` | Every event |
| `properties.goarch` | Go's `runtime.GOARCH` | Every event |
| `properties.install_age_hours` | Whole hours since `Options.InstalledAt`, with a minimum of zero | When `InstalledAt` is set |
| `properties.$lib` | Library name supplied by posthog-go, `posthog-go` | Every event |
| `properties.$lib_version` | Version of the posthog-go SDK in the application | Every event |
| `properties.$process_person_profile` | Kit sets `false` to disable person profile processing | Every event |
| `properties.$geoip_disable` | Kit sets `true` to disable GeoIP lookup | Every event |
| Product properties under `properties` | Values accepted by each event's `AllowProperty` and `RequireProperty` filters in `WithAllowedEvent` | When supplied and accepted; required properties must be accepted before queueing |

Shared properties belong to kit and override product values with the same names. Products document their own event names, property names, and allowed values.

The public project key, from `Options.APIKey` or set at link time, appears as `api_key` in the batch envelope, outside the events. `$geoip_disable` turns off GeoIP lookup. PostHog project settings control IP address retention; this flag does not configure retention.
